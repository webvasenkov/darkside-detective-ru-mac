# The Darkside Detective — русский перевод для Mac

Ручная установка для **Steam-версии macOS**. Автор перевода — **Prometheus Project**.

## Как установить

1. Скачайте **Darkside-RU-Mac-files.zip** в [последнем выпуске](https://github.com/webvasenkov/darkside-detective-ru-mac/releases) и распакуйте двойным щелчком.
2. Откройте **Steam → Библиотека**. Нажмите правой кнопкой на **The Darkside Detective → Управление → Просмотреть локальные файлы**. Откроется папка игры в Finder.
3. Оставьте Finder открытым. Закройте игру и выйдите из Steam через **Steam → Выход**.
4. В Finder нажмите правой кнопкой на приложение игры **.app → Показать содержимое пакета**. Откройте **Contents → Resources → Data**.
5. В распакованном архиве откройте **1-Data**. Выделите все файлы (**⌘A**), скопируйте (**⌘C**) и вставьте в папку **Data** игры (**⌘V**). Подтвердите **«Заменить»** для всех совпадающих файлов.
6. В папке **Data** игры откройте **Managed**. Скопируйте туда единственный файл из папки **2-Managed** архива. Подтвердите **«Заменить»**.
7. Откройте Steam и запустите игру. В настройках языка выберите **English / ENGLISH** — этот пункт включает русский перевод.

**Копируйте файлы внутри папок. Сами папки Data и Managed целиком не заменяйте.**

## Совместимость

Подготовлено по файлам Steam-версии macOS **2.127.2.165**, Unity **2022.3.35f1**. Для других сборок совместимость не подтверждена.

Это тестовый выпуск: файлы и шрифты проверены, фактический запуск игры на Mac ещё не подтверждён. При блокировке изменённой игры macOS может потребоваться обновление её локальной подписи.
